Install to Home Screen
Turns this into an app-like icon. Works best over HTTPS.
  1. Open this page in Safari.
  2. Tap the Share icon.
  3. Choose “Add to Home Screen”.
  4. Launch from the new icon (recommended).
Offline mode requires a secure origin (HTTPS). For personal use, a free static host (GitHub Pages / Netlify / Cloudflare Pages) is the easiest option.
